# Port the Windows overlay to macOS on the same Tauri shell

Carry Codex Meter to macOS by keeping the Tauri 2 shell and adding a darwin adaptation layer, instead of starting a native SwiftUI rewrite. The window contract, tray, JSON-RPC quota read (ADR-0001), and the bigmodel monitoring endpoint (ADR-0004) are platform-independent; only executable discovery (npm-vendored `codex-darwin-*` binaries plus PATH-free fallback locations for Finder launches), the TomatoCloud probe (`ps` and `scutil --proxy` instead of `tasklist.exe` and the registry), the home-directory convention (`HOME` before `USERPROFILE` for `~/.zcode`), and bundling (`tauri.macos.conf.json` enabling `macOSPrivateApi` for the transparent window and the Accessory activation policy instead of `skipTaskbar`) differ. This keeps one codebase and one test suite across both platforms and accepts WKWebView as the macOS counterpart of WebView2.
