# 04 — Windows 浮窗交互与偏好

**What to build:** 用户可以把浮窗放在不遮挡工作的地方，切换鼠标穿透、展开详情或打开设置，并在下次手动启动时恢复位置、透明度与动效偏好；应用始终保持可恢复、可键盘操作且绝不注册开机启动。

**Blocked by:** 01 — 可运行的配额浮窗闭环

**Status:** ready-for-agent

- [ ] 浮窗支持拖动、始终置顶、展开/收起和一个不会让用户失去控制的鼠标穿透切换路径。
- [ ] 右键设置支持透明度与减少动效，关键控件有键盘焦点和明确反馈。
- [ ] 位置与显示偏好仅保存在本地非秘密配置中，并能在隔离数据目录重启后恢复。
- [ ] 自动检查确认应用不创建 Run 键、启动任务或其他开机启动注册。
